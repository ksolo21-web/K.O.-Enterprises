# Public geographic reference snapshot

An isolated processing branch retaining only already-public government/OpenStreetMap data for Rochester-area map verification. This is not a user territory map. No private user files, assignment boundaries, congregation information, names, credentials, or project archives are included. The existing main branch is unchanged.

Government sources: Oakland County public GIS road centerlines and tax-parcel geometry/land-class attributes. OpenStreetMap source: https://www.openstreetmap.org/copyright (Open Database License). The county service URLs, query extents, retrieval dates, feature counts, ID checks, and hashes are retained in the archive. Owner/taxpayer/mailing/contact columns are excluded. No geographic record is a new user assignment.

## Working method

Give each advisor the same raw revision, a bounded question and an exclusive report path. Collect independent first findings before sharing conclusions. Resolve disagreements from source evidence, not votes. Carry out useful authorized repairs and drafts; seek a focused rereview of a material fix. Stop the assignment when its deliverable is accepted. Read the current user mandate before applying an older business record.

The current mandate is fresh ideas, legal profit, $0 external spending, self-service delivery and low owner effort. Keep OANDA practice activity separate. The existing pause remains; routine internal work continues. A role is not authority to open an account, accept costs, publish marketing, contact people, file taxes or move money.

For each later cycle, preserve prior reviews, update the current checkpoint and aggregate actuals, record decisions, and complete the next useful experiment or remediation. Do not count advisors, code, free evaluations, hypothetical sales or virtual trading gains as revenue.

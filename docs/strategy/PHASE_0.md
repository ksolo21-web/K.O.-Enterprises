# Phase 0 — Founding Control Plane

## Objective

Create the smallest durable system that makes internal venture work useful, truthful, reviewable, and safe. Phase 0 ends with a credible path to test demand; it does not end with invented market validation or a pretend autonomous corporation.

## In scope

- human authority and approval policy;
- pause and zero-spend defaults;
- local durable records for opportunities, evidence, experiments, approvals, decisions, costs, revenues, risks, and audit events;
- transparent scoring with evidence freshness;
- a concise CEO report separating operator-recorded transaction statuses from estimates and clearly disclosing the lack of external financial verification;
- deterministic policy tests and secret-free CI;
- preservation of founding prompts as non-binding design history.

## Out of scope

- legal formation, banking, taxes, contracts, domains, and payment accounts;
- production credentials, public deployment, outreach, paid services, and customer-data collection;
- broad market claims without current sourced evidence;
- a customer-facing product before a demand test supports it.

## Exit gate

Phase 0 is complete when local state survives restarts; the pause, budget, approval, and audit paths are tested; reports expose unknowns honestly; and no paid service or secret is needed. Passing this gate authorizes research and proposal work, not external execution.

## First validation path

1. Select 5–10 narrow problem spaces using recent public evidence.
2. Capture at least one strong economic/behavioral signal and independent corroboration for finalists.
3. Identify the user, budget holder, cost of inaction, current workaround, competitors, reachability, and why the gap persists.
4. Score candidates and have an independent reviewer argue the counter-thesis.
5. Choose one candidate whose weakest assumption can be tested at `$0` or with a separately approved hard limit.
6. Define a truthful landing/demo/interview/listing test, target-user channel, success threshold, kill threshold, timebox, analytics, and rollback.
7. Complete legal, privacy, security, and claims review.
8. Submit one exact CEO approval packet for external exposure.
9. Measure qualified behavior and decide without moving the thresholds.

No amount of code or agent activity substitutes for a target user's observable commitment.

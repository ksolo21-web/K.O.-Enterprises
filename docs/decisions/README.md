# Decision Records

Use this directory for decisions that need more context than `DECISIONS.md`.

Each record should include:

- ID, title, date, owner, and status (`proposed`, `accepted`, `rejected`, `superseded`);
- observed evidence and assumptions;
- options considered, including doing nothing;
- constitutional, approval, legal, security, privacy, cost, and reversibility analysis;
- decision and measurable consequences;
- expiry or revalidation date where conditions can change;
- links to the approval and audit records, if any.

Never delete or silently rewrite an accepted record. Add a new decision that explicitly supersedes it.
